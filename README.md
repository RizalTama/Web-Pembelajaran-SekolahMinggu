# Sistem Informasi Sekolah Minggu

Aplikasi web untuk mengelola data guru, siswa, jadwal, kegiatan, absensi, materi, dan nilai rapor sekolah minggu. Dibangun dengan PHP native dan MySQL/MariaDB.

## Role

- **Admin** — kelola data guru, siswa, jadwal, dan kegiatan.
- **Guru** — input absensi, materi, dan nilai rapor.
- **Siswa** — lihat jadwal, absensi, materi, dan rapor.

## Tech Stack

- PHP native (tanpa framework)
- MySQL/MariaDB
- Tailwind CSS
